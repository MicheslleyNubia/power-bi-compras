# Dashboard de Compras

## Objetivo

Projeto desenvolvido para prática de análise de dados e construção de dashboards utilizando Power BI.

## Ferramentas Utilizadas

- Power BI
- Excel

## Indicadores Analisados

- Volume de compras
- Evolução dos gastos
- Distribuição por categorias
- Indicadores financeiros

## Resultado

O dashboard foi desenvolvido para proporcionar uma visão consolidada das informações de compras e facilitar o acompanhamento dos principais indicadores.

## Aprendizados

Durante este projeto pratiquei conceitos de modelagem de dados, criação de métricas e desenvolvimento de visualizações voltadas ao suporte gerencial.
